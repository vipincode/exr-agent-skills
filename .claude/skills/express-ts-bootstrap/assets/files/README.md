## Prerequisites

- Node.js {{NODE_MAJOR}} (see `.nvmrc`)
- MongoDB (or `docker compose up -d` to run the bundled local instance)

## Setup

```bash
{{PM}} install         # also installs the husky pre-commit hook
cp .env.example .env   # then edit values; JWT_SECRET must be >= 32 chars
```

`.env` is loaded automatically by the `dev`/`start` scripts via Node's native
`--env-file=.env` flag — no `dotenv` needed. If the app exits at startup with an
env validation error, your `.env` is missing or has bad values.

## Scripts

| Script                     | What it does                                                   |
| -------------------------- | -------------------------------------------------------------- |
| `{{PM}} run dev`           | Wipes `dist/`, runs `tsx watch` from source with `.env` loaded |
| `{{PM}} run build`         | Wipes `dist/`, compiles `src/` (no tests) to `dist/`           |
| `{{PM}} start`             | Runs the compiled server with `.env` loaded; build first       |
| `{{PM}} run typecheck`     | Type-checks source and tests                                   |
| `{{PM}} run lint`          | ESLint, including the module-boundary rules                    |
| `{{PM}} test`              | All tests (unit + integration)                                 |
| `{{PM}} run test:unit`     | Unit tests only — no database                                  |
| `{{PM}} run test:int`      | Integration tests — real app + in-memory MongoDB               |
| `{{PM}} run test:coverage` | All tests with V8 coverage                                     |
| `{{PM}} run clean`         | Removes `dist/`                                                |

The first integration run downloads a MongoDB binary for `mongodb-memory-server` (cached afterwards).

## Structure in one minute

```
src/routes.ts            ← one mount line per module (all under /api/v1)
src/modules/<name>/
  index.ts               ← the module's public API — the only file others import
  <name>.routes.ts → controller → service → repository → model
  <name>.schema.ts       ← Zod input + per-route request bundles
  <name>.mapper.ts       ← what a response is allowed to contain
  __tests__/             ← unit (*.test.ts) + integration (*.int.test.ts)
```

Lint fails on boundary violations (importing another module's internals, touching a model
outside its repository), and the pre-commit hook runs lint.
